Assignment 1: Network Attack Detection and Reporting

Overview

This project involved setting up a Cowrie honeypot in an Ubuntu virtual machine and using Kali Linux to perform network reconnaissance and examine network traffic.

Objectives

* Deploy a honeypot in a controlled lab environment.
* Perform network reconnaissance using Nmap.
* Capture and inspect network traffic using Wireshark.
* Document observations and security findings.

Tools Used

* Ubuntu Linux
* Kali Linux
* Cowrie honeypot
* Nmap
* Wireshark
* VirtualBox

Methodology

1. Prepared the Ubuntu virtual machine for the Cowrie honeypot.
2. Configured and initialized the Cowrie environment.
3. Used Kali Linux to perform reconnaissance against the lab target.
4. Captured network traffic with Wireshark for examination.
5. Prepared a report documenting the activities and evidence.

Results and Evidence

Screenshots, relevant logs, the network capture (PCAP), and the final report will be added to this folder as they are organized.

Security Lessons

The exercise demonstrated the value of honeypots for observing suspicious activity and the importance of network traffic analysis when investigating potential security events.

Scope

Testing was performed in a controlled educational lab environment.
