Hands-on cybersecurity projects covering network attack detection, vulnerability assessment, web application security, and log analysis.
Cybersecurity Portfolio

Welcome to my cybersecurity portfolio. This repository showcases practical cybersecurity assignments completed during my training at Bincom Academy.

Through these projects, I have gained hands-on experience with Linux environments, network reconnaissance, traffic analysis, vulnerability testing, web application security, firewall validation, and security log analysis.

Projects

1. Network Attack Detection and Reporting

Tools: Cowrie, Ubuntu, Kali Linux, Nmap, Wireshark

* Worked on deploying and configuring a Cowrie SSH/Telnet honeypot in an Ubuntu virtual machine.
* Used Kali Linux and Nmap to perform reconnaissance against the lab environment.
* Used Wireshark to capture and examine network traffic.
* Documented the lab setup, testing activities, observations, and supporting evidence.

Key learning: Honeypot deployment, network reconnaissance, packet analysis, and security incident documentation.

2. Vulnerability Scanning and Exploit Simulation

Tools: DVWA, Kali Linux, Metasploit, OpenVAS/GVM, Docker

* Deployed Damn Vulnerable Web Application (DVWA) in a controlled Docker environment.
* Tested SQL injection and cross-site scripting (XSS) vulnerabilities in the lab.
* Explored Metasploit and performed controlled security testing.
* Attempted to configure OpenVAS/Greenbone Vulnerability Management (GVM) for vulnerability scanning.
* Documented testing evidence, setup challenges, and recommended security improvements.

Key learning: Web application vulnerability testing, exploit simulation, vulnerability management concepts, and remediation planning.

3. Attack and Defend Web Applications

Tools: DVWA, ModSecurity, OWASP Core Rule Set (CRS), Docker, Kali Linux

* Tested SQL injection and XSS against DVWA in a controlled lab environment.
* Configured ModSecurity as a Web Application Firewall (WAF).
* Created custom WAF rules and checked the Apache configuration.
* Re-tested the application and observed the WAF blocking the tested SQL injection and XSS requests.
* Collected screenshots and log evidence to support the security validation report.
* Worked on deploying PrestaShop as an additional web application security exercise.

Key learning: Web application attack simulation, WAF configuration, defensive rule validation, and security evidence collection.

4. Security Log Analysis and Risk Assessment

Tools: Elasticsearch, Kibana, security log data, dashboards

* Worked with security-related log data in an Elasticsearch-based environment.
* Configured a visualization to examine the distribution of logged events using an available message keyword field.
* Built a dashboard and captured a screenshot of the visualization.
* Prepared documentation explaining the analysis and associated security risks.

Key learning: Security log analysis, dashboard visualization, interpreting event patterns, and communicating potential risks.
